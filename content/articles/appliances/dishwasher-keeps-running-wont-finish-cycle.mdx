quickAnswer: "If the cycle genuinely never ends — running well past its longest normal setting with no sign of reaching the 'clean' or 'end' light, even after an hour or more of extra time — the machine is likely stuck waiting on a condition it can't satisfy: a soil/turbidity sensor that thinks the water is still dirty, or a heating circuit that never reaches target temperature. This is a different, more persistent pattern than simply taking longer than usual."
symptoms:
  - "The cycle runs well beyond its longest normal setting with no end in sight"
  - "You have to manually cancel the cycle to stop it"
  - "The machine may seem to repeat the same wash/rinse pattern over and over"
  - "This has happened more than once, not as a single unusual occurrence"
causes:
  - title: "Soil/turbidity sensor stuck reporting dirty water"
    description: "This sensor tells the machine when water is clean enough to move on. If it's malfunctioning or coated in residue, it can perpetually report dirty water, causing the machine to keep re-washing indefinitely."
  - title: "Heating element or thermostat never reaching target temperature"
    description: "If the machine is programmed to wait for a specific water temperature before certain stages and that temperature is never reached, it can hold indefinitely at that point in the cycle."
  - title: "Control board stuck in a loop"
    description: "A control board fault can cause the machine to repeat a stage rather than progressing, similar in concept to a computer stuck in a retry loop."
  - title: "A drain issue preventing progression"
    description: "If the machine can't confirm successful draining between stages, some models will keep attempting rather than moving on, which can look like the cycle simply won't finish."
safeChecks:

  - "Listen for whether the machine seems to be repeating the same sounds (fill, wash, drain) in a loop rather than progressing through different stages."
  - "Check for standing water that isn't clearing between apparent stages, which could point to a drainage contribution — see our standing water guide."
  - "Note whether this has happened on more than one occasion, which supports a genuine developing fault rather than a one-off."

The real test here is whether the machine is stuck, not just slow: running noticeably past the longest normal setting for your model with no progress is a meaningfully different situation from a single longer-than-usual cycle.

| What you notice | Most likely cause |
|---|---|
| Machine seems to repeat wash/rinse over and over | Soil/turbidity sensor stuck |
| Machine pauses and won't progress past one stage | Heating element not reaching target temperature |
| Behavior is inconsistent, no clear pattern | Control board fault |
| Standing water present and not clearing | Drainage contributing to the stall |
