quickAnswer: "If lights and the display work but pressing Start does nothing, the machine almost always thinks the door isn't securely closed, or a control/child lock is engaged — both are checkable in under a minute before assuming anything is actually broken."
symptoms:
  - "Display, lights, and button beeps all work normally"
  - "Pressing Start produces no response, no error, and no cycle beginning"
  - "A door/lock icon may be flashing on the display"
  - "The machine may have been recently used by a child or someone unfamiliar with the controls"
causes:
  - title: "Door or lid not fully latched"
    description: "The machine won't start — as a safety measure — unless it confirms the door is securely closed, even if it visually looks shut."
  - title: "Control lock or child lock engaged"
    description: "Most machines have a lock feature (often activated by holding a specific button) that disables all controls except unlocking, to prevent accidental changes mid-cycle or by children."
  - title: "Selected cycle requires an option you haven't set"
    description: "Some machines won't start if a required selection (like water temperature on certain models) hasn't been made, though this is less common than a door or lock issue."
  - title: "Start button itself is worn or unresponsive"
    description: "On machines with physical (not touch) buttons, the start button can wear out and stop registering presses reliably after years of use."
safeChecks:
  - "Open and firmly reclose the door or lid, listening for a distinct latch click."
  - "Check your control panel for a lock icon, and look up your model's specific button-hold combination to unlock it if engaged."
  - "Try pressing Start firmly and holding for a full second or two, since some models require a deliberate press rather than a light tap."
  - "Check if any indicator light suggests a required setting hasn't been selected yet."
steps:
  - title: "Check for a control lock"
    description: "Look for a small lock icon on the display. If present, most machines unlock by holding a specific button (often labeled 'Control Lock' or similar) for 3 seconds — check your manual for the exact combination."
  - title: "Reclose the door firmly"
    description: "Open the door fully, clear anything caught in the frame or seal, and close it again with a firm, deliberate push until you hear or feel the latch engage."
  - title: "Power-cycle if needed"
    description: "If the lock isn't the issue and the door is confirmed shut, unplug the machine for a minute and restart, which clears many minor control glitches."
  - title: "Test the start button"
    description: "If nothing else works, try pressing Start firmly several times — a worn physical button may need more deliberate pressure to register."
dontDo:
  - "Don't assume the machine is broken before checking for a control lock — it's one of the most common causes of an apparently unresponsive Start button."
  - "Don't force the door shut if it isn't latching normally — this can bend the latch mechanism."
  - "Don't repeatedly mash the Start button rapidly, which can sometimes register as multiple conflicting inputs on touch panels."
whenToCallPro:
  - "The control lock is confirmed off and the door latches normally, but Start still does nothing."
  - "The physical start button feels loose, sunken, or doesn't click at all."
  - "You suspect a control board fault rather than a lock or door issue."
faqs:
  - q: "How do I know if control lock is on?"
    a: "Most machines show a small padlock icon on the display when it's active. The exact unlock combination (usually holding one or two buttons for a few seconds) varies by brand — check your manual if the icon is present."
  - q: "Why would the door look closed but the machine disagree?"
    a: "The door switch, not your eyes, determines whether the machine considers it closed. A small gap, something caught in the seal, or a latch that's slightly misaligned can all cause this mismatch."
  - q: "Could this be a bigger electrical problem?"
    a: "It's unlikely if the display and lights work normally — that confirms the machine is receiving power fine. This symptom is almost always the door/lock/button level, not a wiring issue."
