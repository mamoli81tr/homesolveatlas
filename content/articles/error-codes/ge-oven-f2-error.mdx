quickAnswer: "F2 means the oven's control detected the cavity exceeding a safe temperature threshold and cut power to the heating elements as a protective measure. GE model manuals and displays sometimes call this appliance a range or stove rather than an oven — the code and the fix are identical either way. This is a safety-relevant fault — unlike a simple communication glitch, it should be taken seriously rather than just reset and ignored if it recurs."

  - "The oven may feel like it was running hotter than the set temperature before the fault appeared"
causes:
  - title: "Stuck relay on the control board"
    description: "If a relay controlling the heating element gets stuck in the 'on' position, the oven can overheat beyond its set point, and the safety system responds by cutting power and showing F2."
  - title: "Failed temperature sensor"
    description: "A sensor reporting an inaccurately high (or genuinely too high) temperature can trigger this protective shutoff even if the true cavity temperature is normal."
  - title: "Self-clean cycle heat buildup"
    description: "Self-clean mode runs at very high temperatures by design, and is a common time for a marginal component to finally trip an overheat fault that doesn't show up during normal baking."
  - title: "Wiring or connector issue near the sensor"
    description: "A loose or damaged connection to the temperature sensor can cause erratic readings that trigger a false overheat signal."
safeChecks:

  - "Once the oven has cooled and is unplugged, check for any obvious burning smell or visible damage near the back wall sensor."
  - "Do not attempt to use the oven again until the cause is understood, given this is a heat-safety-related fault."
